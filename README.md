# video.surf — client-ready prototype

Updated desktop + mobile Studio/dashboard treatment, while keeping the existing video.surf visual universe.

### Key fixes
- Real surf photography is now integrated into the Studio dashboard: latest shoot, recent shoots, and private sessions.
- The Studio illustration is used as a large editorial banner rather than a small decorative image.
- Desktop header is simplified and balanced: logo, Explore / How it works / For photographers, then Log in / Sign up / Account / EN.
- Studio hero now clearly carries `video.surf / photographer workspace` so photographers see the product name when showing the dashboard on the beach.
- Primary actions remain coral; navigation remains white pills; Fraunces + Sora and the original sand/ocean/coral palette are preserved.
- Mobile keeps the native app chrome/tab bar and uses the same Studio content in a compact single-column workspace.

## Run

```bash
npm install
npm run dev
```
